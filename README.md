# nba-ranker

A web tool for ranking your favorite NBA players.

## Player data

`data/players.json` contains every NBA All-Star with bio info, career per-game
averages (regular season and playoffs), and accolade counts (All-Star, All-NBA,
MVP, Finals MVP, championships, DPOY, etc., with the seasons they were won).

It's generated by `scripts/fetch_players.py`, which takes the All-Star list from
[Wikipedia](https://en.wikipedia.org/wiki/List_of_NBA_All-Stars) and pulls stats
and awards from stats.nba.com via [`nba_api`](https://github.com/swar/nba_api).

```powershell
python -m pip install -r scripts/requirements.txt
python scripts/fetch_players.py            # ~20-25 min; cached and resumable
python scripts/fetch_players.py --limit 5  # quick test
```

Run it from a home connection — stats.nba.com usually blocks cloud/CI IPs.
Responses are cached in `scripts/.cache/`; pass `--refresh` to re-fetch (e.g.
at the start of a new season). If a new All-Star's name doesn't match NBA.com,
add it to `MANUAL_IDS` in the script.
