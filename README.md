# nba-ranker

A web tool for ranking your favorite NBA players. Pick a group (Active
All-Stars, MVPs, or the Top 75), then choose between two players at a time until
your ranking is settled — either a full ranking or just your Top 10.

## Running locally

It's a static site with no build step. Serve the repo root and open it:

```powershell
python -m http.server 8000   # then visit http://localhost:8000
```

It's hosted on GitHub Pages straight from the root of `main`.

- `index.html`, `css/`, `js/app.js` — UI (setup → compare → results)
- `js/sorter.js` — the ranking algorithm. Full rankings use binary insertion
  sort; Top 10 uses a knockout tournament where each later pick only replays
  the previous winner's path. The sort is re-run against the saved list of
  picks, so progress (in `localStorage`) and undo come for free.

## Player data

`data/players.json` contains every NBA All-Star plus every winner of an
individual award (MVP, Finals MVP, DPOY, ROY, Sixth Man, Most Improved,
All-Star Game MVP, Conference Finals MVP), with bio info, career per-game
averages (regular season and playoffs), and accolade counts (All-Star, All-NBA,
MVP, Finals MVP, championships, DPOY, etc., with the seasons they were won).

It's generated by `scripts/fetch_players.py`, which takes the All-Star list and
each award's winners from Wikipedia (e.g.
[List of NBA All-Stars](https://en.wikipedia.org/wiki/List_of_NBA_All-Stars))
and pulls stats and awards from stats.nba.com via
[`nba_api`](https://github.com/swar/nba_api). Award winners who aren't
All-Stars are kept only if NBA.com confirms the award.

```powershell
python -m pip install -r scripts/requirements.txt
python scripts/fetch_players.py            # ~20-25 min; cached and resumable
python scripts/fetch_players.py --limit 5  # quick test
```

Run it from a home connection — stats.nba.com usually blocks cloud/CI IPs.
Responses are cached in `scripts/.cache/`; pass `--refresh` to re-fetch (e.g.
at the start of a new season). If a new player's name doesn't match NBA.com,
add it to `MANUAL_IDS` in the script. If NBA.com is missing an award, add it
to `AWARD_CORRECTIONS`.
